# Media Kolfat

**Media Kolfat takes care of your media.**

Media Kolfat is a Windows application for organizing and managing photo and video collections with a focus on practical, safe and predictable media organization.

> **Official distribution:** Media Kolfat will be distributed through the Microsoft Store. This public repository does not contain the proprietary application source code or downloadable production installers.

## Status

Media Kolfat is under active development.

The first public production release will be announced here and on the official Kolfat website.

For security and intellectual-property protection, this repository does **not** contain:

- Credentials or secrets
- Production installers
- Private development plans

The proprietary application source is maintained separately in a private repository.

## Community

Before opening an issue, please check existing issues to avoid duplicates.

For bug reports, include:

- Media Kolfat version
- Windows version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant logs with personal information and file paths removed

Please do not publish security vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).
