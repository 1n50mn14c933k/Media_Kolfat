# MEDIA KOLFAT Release Checklist

This checklist is for the public-facing release process. Proprietary build, signing and implementation procedures remain private.

## Before 1.0.0

- [ ] Final production build passes functional validation
- [ ] Large-library performance validation completed
- [ ] Metadata/date fallback behavior validated
- [ ] Thumbnail/preview fallback behavior validated
- [ ] Microsoft Store package validated
- [ ] Microsoft Store listing text reviewed
- [ ] Final application version confirmed
- [ ] Final production screenshots captured
- [ ] Final MEDIA KOLFAT branding verified
- [ ] Privacy Policy reviewed against production behavior
- [ ] Terms of Use reviewed
- [ ] Disclaimer reviewed
- [ ] Third-Party Licenses reviewed
- [ ] Support page reviewed
- [ ] SECURITY.md supported-version table updated
- [ ] CHANGELOG.md updated with final 1.0.0 contents
- [ ] GitHub Release notes prepared
- [ ] Microsoft Store URL added to README after publication
- [ ] Repository description, homepage and topics configured
- [ ] Empty/unused GitHub Wiki disabled
- [ ] Final public repository audit confirms no proprietary source, secrets or installer artifacts

## Public release

- [ ] Publish / make available through Microsoft Store
- [ ] Create GitHub Release: `MEDIA KOLFAT 1.0.0`
- [ ] Mark `1.0.0` as released in CHANGELOG.md
- [ ] Update README status from release preparation to released
- [ ] Add authoritative Microsoft Store link
- [ ] Verify all website/legal/support links
- [ ] Verify GitHub bug and feature request forms

## After release

- [ ] Monitor public bug reports
- [ ] Triage reproducible issues
- [ ] Keep security reports private
- [ ] Keep roadmap limited to public commitments
- [ ] Update CHANGELOG.md for every production release

Official support: https://kolfat.app/support/
