# Media Kolfat Support

## Bug reports

Use GitHub Issues for reproducible application bugs that are safe to discuss publicly.

Please include:

1. Media Kolfat version
2. Windows version
3. Steps to reproduce
4. Expected result
5. Actual result
6. Relevant sanitized logs or screenshots

Remove personal names, private file paths, media content, credentials and other sensitive data before posting.

## Feature requests

Feature requests are welcome through GitHub Issues.

Describe the problem you want solved rather than only describing a proposed implementation.

## Security issues

Do not report vulnerabilities through public Issues.

See [SECURITY.md](SECURITY.md).

## Installation

Official production installation will be provided through the Microsoft Store.

This repository does not distribute production installers.
