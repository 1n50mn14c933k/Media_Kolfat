# Contributing to Media Kolfat

Thank you for helping improve Media Kolfat.

Media Kolfat is proprietary software, so this public repository is not used for application-source contributions.

## You can contribute by

- Reporting reproducible bugs
- Suggesting useful features
- Improving public documentation through an issue
- Providing clear usability feedback
- Reporting security issues privately

## Please do not submit

- Reverse-engineered proprietary source
- Decompiled application code
- Credentials or secrets
- Personal media or private user information
- Public vulnerability disclosures for unpatched issues

## Issue quality

Good reports are specific, reproducible and sanitized of sensitive information.
