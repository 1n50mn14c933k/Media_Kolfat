# MEDIA KOLFAT Release Checklist

This checklist tracks the public-facing release process. Proprietary build, signing and implementation procedures remain private.

## First public release

- [x] Final production build passed functional validation
- [x] Large-library performance validation completed
- [x] Metadata/date fallback behavior validated
- [x] Thumbnail/preview fallback behavior validated
- [x] Microsoft Store package validated
- [x] Microsoft Store listing published
- [x] Final application version confirmed
- [x] Final production screenshots captured
- [x] Final MEDIA KOLFAT branding verified
- [x] Privacy Policy reviewed against production behavior
- [x] Terms of Use reviewed
- [x] Disclaimer reviewed
- [x] Third-Party Licenses reviewed
- [x] Support page reviewed
- [x] Microsoft Store URL added to README
- [x] Repository description, homepage and topics configured
- [x] Empty/unused GitHub Wiki disabled
- [x] Final public repository audit confirmed no proprietary source, secrets or installer artifacts
- [x] MEDIA KOLFAT published through the Microsoft Store
- [x] README status updated to released
- [x] Authoritative Microsoft Store link added

## Remaining GitHub release housekeeping

- [ ] Publish the corresponding GitHub Release entry
- [ ] Keep release notes synchronized with the production version in the Microsoft Store

## After release

- [ ] Monitor public bug reports
- [ ] Triage reproducible issues
- [ ] Keep security reports private
- [ ] Keep roadmap limited to public commitments
- [ ] Update CHANGELOG.md for every production release
- [ ] Maintain Microsoft Store and website links
