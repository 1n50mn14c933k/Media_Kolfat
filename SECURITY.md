# Security Policy

## Reporting security vulnerabilities

Please **do not open a public GitHub issue** for suspected security vulnerabilities.

Use GitHub's private vulnerability reporting or security-advisory mechanism if it is available for this repository. If that mechanism is unavailable, contact the repository owner privately through GitHub.

When reporting an issue, include enough information to reproduce the problem while avoiding unnecessary personal data.

## Please do not publish

Do not publish:

- Exploit details for an unpatched Media Kolfat vulnerability
- Credentials, tokens, passwords or private keys
- Personal media or private user data
- Sensitive file-system paths or account information
- Code-signing material

## Supported versions

Before the first public release, no production version is considered supported.

After release, supported versions and security-update policy will be documented here.

## Official software distribution

Official Media Kolfat production builds are distributed through the Microsoft Store.

Do not trust production installers from third-party mirrors unless Kolfat explicitly identifies that source as official.
